# 참고 서비스 분석

> 이 문서는 최초 한국어 프로토타입을 만들 때의 분석 기록입니다. 현재 버전은 일본어 `rireki`로 디자인과 정보 구조를 재구성했으며, 선택형 회원가입 기능이 추가되었습니다. 최신 동작 범위는 [README](../README.md), [인증 설정](auth-setup.md), [다국어 구조](localization.md)를 참고하세요.

분석 대상: [doda 이력서 작성 도구](https://doda.jp/guide/rireki/builder/)

## 공개 화면에서 확인한 사용자 흐름

1. 첫 화면에서 무료 작성 CTA 또는 기존 이력서 편집 링크 선택
2. 회원가입 또는 로그인
3. 안내에 따라 항목 입력
4. 작성 데이터 저장 및 재편집
5. Word 파일 다운로드

로그인 진입까지 확인했으며, 인증 뒤 편집기 화면은 확인하지 않았습니다. 편집기의 구체적인 단계, 입력 항목, 검증 방식은 원본과 같다고 단정할 수 없습니다.

## 시각적 특징

- 흰색을 중심으로 파랑과 민트를 사용해 신뢰감과 가벼운 인상을 줍니다.
- 주황색 CTA를 배경과 대비시켜 주요 행동을 강조합니다.
- 스마트폰 안의 이력서로 결과물과 모바일 지원을 함께 보여줍니다.
- 긴 소개 페이지를 짧은 구역과 바로가기 메뉴로 나눕니다.
- 사용 흐름과 장점을 각각 3개로 제시해 처음 사용하는 사람의 부담을 낮춥니다.

이번 구현은 원본 로고나 이미지를 복제하지 않고, 같은 시각적 원칙에 자체 브랜드·일러스트·문구를 적용했습니다.

## 프로토타입의 동작 범위

React와 Vite 기반의 클라이언트 애플리케이션입니다. 새로 작성하거나 저장된 내용을 불러와 4단계로 편집할 수 있습니다. 학력과 경력은 반복 항목을 지원하며, 사진은 최대 400px로 축소한 뒤 브라우저에 저장합니다. 입력 내용은 즉시 미리보기에 반영됩니다.

PDF는 한글 렌더링을 위해 화면을 이미지로 변환합니다. Word는 편집 가능한 `.docx`를 생성합니다. 서버·회원 인증·기기 간 동기화가 없는 초기 구현이며, 실제 서비스 출시 시 해당 기능과 개인정보 처리 정책을 구체화해야 합니다.
