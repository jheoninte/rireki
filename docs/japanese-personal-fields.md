# 日本語の職種ガイド・日付・郵便番号

`japanese-jobs.js` に営業、事務・管理、企画・マーケティング、ITエンジニア、クリエイティブ、販売・接客・サービス、医療・福祉・教育、製造・建築・物流の8分類と架空の記入例を定義しています。既存のIT・クリエイティブ・マーケティング用キーは維持しています。AIコーチの入力チェックにも8分類を追加しました。稼働中のAI機能に反映するにはEdge Functionの再デプロイが必要です。

日本語の新規下書きは端末のローカル日付を記入日の初期値にします。既存の記入日は変更しません。空の記入日を持つ旧下書きを初めて開いた場合も初期値を補います。記入日はテキスト入力のため西暦・和暦で手動修正できます。

満年齢は生年月日と記入日から計算します。西暦の年月日・ハイフン・スラッシュ・ドット、明治以降の主要な和暦・元年・全角数字を処理します。不正な日付・未来の生年月日からは年齢を生成しません。年齢を直接編集した場合は保存・再読込後もその値を維持し、生年月日または記入日を変更すると再計算します。

現住所の `postalCode` と別の連絡先の `contactPostalCode` を追加しました。7桁の数字を `123-4567` に整形し、固定履歴書の住所欄に `〒` とともに表示します。既存の住所に郵便番号を含む下書きも使用できます。新しい専用欄を使った場合は住所先頭の郵便番号を重複表示しません。Wordも原本の住所セルへ差し込み、表の構造・A4の2ページ構成は変更していません。

追加項目は既存のJSON下書きに保存するためDBスキーマ変更は不要です。自動入力された記入日だけでサンプル置き換え確認やアカウント案内を発生させないようにしています。
