# 한국어 초기 버전

한국어 서비스명과 홈 H1은 **바로 이력서**입니다.

한국형 경력기술서(`career-description`)를 세 번째 무료 문서로 추가했습니다. 경력 요약 → 핵심 역량 → 회사별 경력·성과 → 주요 프로젝트·성과 → 관련 자격·어학 순으로 구성합니다. 사진·영문 이름·생년월일·주소·학력·자기소개·지원동기는 출력하지 않으며 원래 초안에는 유지합니다. 폼·작성 진행률·제출 전 점검·PDF·Word 출력도 이 구성을 따릅니다. 모던·스탠더드와 같은 한국어 초안을 공유하므로 서로 다른 내용의 여러 문서를 별도 보관하는 기능은 아닙니다.

클라우드에서 새 문서 종류를 저장하려면 `202611200005_korean_career.sql`을 기존 마이그레이션 다음에 적용해야 합니다. 이 변경은 로컬 PostgreSQL 테스트에서 검증했으며 원격 DB에는 적용하지 않았습니다.

경력기술서 PDF는 항목·경력·프로젝트와 실제 텍스트 줄의 위치를 기준으로 페이지를 나눕니다. 페이지 안에 들어가는 항목은 가능하면 함께 출력하고, 긴 내용은 줄 사이에서 나눕니다. PDF는 기존과 동일하게 이미지 형식입니다.

스탠더드는 한국어 전용 `KoreanStandardResume.jsx`로 렌더링합니다. 화이트·블루·슬레이트 색상과 읽기 쉬운 본문 크기, 인적사항 표, 기간/내용을 나눈 경력·프로젝트·학력 목록을 사용합니다. 빈 선택 개인정보와 빈 항목은 출력하지 않습니다. 공통 로그인·가입·복구 화면은 `site-refresh.css`에서 같은 블루 디자인을 적용합니다. 일본 후생노동성 고정 이력서에는 이 서식 변경을 적용하지 않습니다.

2026-11-20 참고: [원티드](https://www.wanted.co.kr/cv/intro)의 직무별 작성 예시, [Canva](https://www.canva.com/ko_kr/resumes/)의 서식 선택·스타일 조정 흐름을 참고했습니다. 문구·이미지·합격 통계는 가져오지 않았습니다. 자체 작성한 일반·사무/개발·IT/디자인/마케팅 가상 예시는 내용 선택이며 추가 템플릿이 아닙니다.

홈의 예시는 네이티브 라디오와 CSS로 전환하여 정적 빌드에서도 동작합니다. 직무 링크는 편집기의 예시 선택만 변경하며 기존 초안을 자동 교체하지 않습니다. 예시 불러오기는 기존 내용이 있으면 교체 확인을 거치고 문서 강조색과 선택 서식은 유지합니다.

검토 단계에서 블루·네이비·차콜 강조색을 선택하면 미리보기·PDF와 Word 제목 색상에 적용됩니다. `accent` 값은 초안과 함께 저장하며 허용 목록으로 정규화합니다. 자동 점검은 이름·연락처 형식·지원 직무·경험 내용·URL 형식·일부 가상 예시 잔존 여부를 확인하며 사실 검증이나 채용 적합성 판단 기능은 아닙니다. 점검 결과는 다운로드를 차단하지 않습니다.

사용자가 확인한 기존 **모던(`modern`)·스탠더드(`classic`) 두 가지** 디자인을 재사용합니다. 개발자·디자이너·마케터용 직군별 서식은 한국어 초기 선택지에 포함하지 않습니다.

## 화면과 경로

- 일본어: `/`, 편집기 `/app/`
- 한국어: `/ko/`, 편집기 `/ko/app/`
- 영어: `/en/`의 준비 중 안내. 아직 영어 편집기는 제공하지 않습니다.

모든 홈·편집기 상단에서 지원 국가를 선택합니다. 단순 문구 변경이 아니라 시장별 홈·허용 템플릿·입력 항목·가이드·예시를 선택합니다. 한국어 홈도 빌드 시 HTML로 생성하므로 JavaScript 없이 서식 선택 링크를 사용할 수 있습니다.

## 한국 기업 지원에 맞춘 초기 구성

기본정보, 경력·프로젝트, 학력, 역량·자격, 자기소개, 검토·다운로드로 나눕니다. 사진·영문 이름·생년월일은 선택입니다. 후리가나, 일본식 성별·만 나이·대체 연락처, 일본 연월표는 한국어 폼에 노출하지 않습니다. 주민등록번호와 가족관계 등 불필요한 민감정보 입력란은 만들지 않습니다.

한국은 기업별 양식과 자기소개서 문항이 다릅니다. 두 템플릿을 공식 통일 양식이라고 표시하지 않으며 기업 지정 양식·블라인드 채용 기준을 우선하도록 안내합니다. 자기소개서는 초기 버전의 자유 서술 항목이며 기업별 문항 편집·자동 분량 검사는 후속 개선 대상입니다.

`src/i18n/ko.js`가 화면·인증·저장·오류·예시 문구를 관리하고 `src/lib/resume-guides-ko.js`가 필드별 팁·예시를 정의합니다. 한국어 AI는 일본어 처리기로 보내지 않으며 초기 버전에서는 표시하지 않습니다. 채용정보 링크는 고용24로 연결하고 작성 정보는 첨부하지 않습니다.

## 저장과 인증

한국어 초안은 `rireki:resume:ko:v1`, 일본어는 `rireki:resume:ja:v1`에 보관합니다. 계정별 키에도 언어가 포함됩니다. 템플릿 변경은 같은 시장의 내용만 유지하며 다른 국가 초안을 자동 복사·번역하지 않습니다. 기존 초안이나 비밀키를 변경하지 않습니다.

원격 DB에 기존 마이그레이션에 이어 `supabase/migrations/202611200004_korean_market.sql`을 적용해야 한국어 클라우드 저장이 가능합니다. `ja`·`ko`별 레코드와 revision·계정별 접근 제어를 유지합니다. 이 작업은 원격 DB에 적용하지 않았습니다.

Supabase의 허용 복귀 주소에는 한국어 `/ko/app/`와 `/reset-password?lang=ko` 경로를 추가해야 합니다. 실제 OAuth·이메일 인증의 원격 설정은 초기 화면 작업에서 변경하지 않았습니다. 초기 검증은 비회원 작성·브라우저 저장·파일 출력 위주로 수행합니다.

## 출력

PDF는 미리보기를 이미지로 출력합니다. Word는 한국어 항목과 프로젝트를 네이티브 문단·표로 생성하고 기본 글꼴로 맑은 고딕을 지정합니다. Word의 배치가 미리보기와 픽셀 단위로 같다는 보장은 하지 않습니다.
