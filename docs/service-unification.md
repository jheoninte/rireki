# 두 화면을 하나의 서비스로 통합

## 주소와 화면

- `/`: 서비스 소개·무료 서식 선택·로그인
- `/#builder`: 통합 편집기
- `/templates/resume-builder/` 및 `/templates/resume-builder/index.html`: 같은 편집기로 이동하는 호환 주소

별도 `folio` 앱은 제공하지 않습니다. 기존 시안의 파란색·흰 카드·5:5 편집/미리보기·섹션 바로가기·상단 저장/PDF·모바일 전환을 `rireki` 메인 앱으로 옮겼습니다. 기존 일본어 서비스의 언어와 브랜드는 유지합니다. 기본 A4 모던 문서 디자인도 시안 스타일로 통일했습니다. 기존의 스탠더드 및 프리미엄 서식 선택은 유지합니다.

두 주소 모두 같은 React 편집기와 같은 인증 세션, 브라우저 키, 다운로드 기능을 사용합니다. OAuth/비밀번호 복구의 반환 경로도 기존 메인 앱을 사용하므로 별도의 계정을 만들지 않습니다. 클라우드·AI·결제의 활성화 여부는 [서버 설정 안내](workspace-setup.md)를 따릅니다.

## 기존 초안 보존

시안의 `folio.resume-template.v1` 원본 키는 삭제하거나 수정하지 않습니다.

1. 게스트 메인 초안이 없고 이전 시안 초안만 있으면 자동 변환해 새 키에 저장합니다.
2. 두 초안이 모두 있으면 메인 초안을 먼저 보여주고 가져오기 선택을 제공합니다.
3. 가져오기를 선택하면 현재 내용·서식을 백업한 뒤 이전 초안을 가져옵니다.
4. ‘읽기 전 내용 복원’으로 두 내용 사이를 되돌릴 수 있습니다.
5. 로그인한 계정으로 게스트/시안 초안을 자동 업로드하지 않습니다. 사용자가 가져오기와 클라우드 저장을 선택합니다.

이름·직무·연락처·주소·소개·스킬·경력·학력·기간을 옮깁니다. 경력의 직책과 상세 성과는 별도 필드로 보존합니다. 이전의 긴 소개/성과도 변환 중 잘라내지 않습니다. 브라우저 저장 공간이 부족하면 오류를 표시하고 원본을 남깁니다.

이전 초안의 자동 인식은 같은 도메인·같은 브라우저의 localStorage에서 동작합니다. 예를 들어 Chrome의 한 프로필에서 작성한 초안은 다른 프로필이나 localhost에서 자동으로 보이지 않습니다. 기기를 바꿔 이어 쓰려면 클라우드 저장 연결과 사용자 선택이 필요합니다.

## 검증

- 로그인·비밀번호 복구·클라우드·결제·비용 제한 기존 테스트 유지
- 별도 초안 자동 변환·동시 존재·원본 보존·긴 본문·계정 분리 테스트
- 사용자 선택 가져오기 → 복원, 모바일 미리보기 → Escape 복귀 테스트
- 브라우저에서 기존 주소의 통합 편집기 이동, 데스크톱/모바일 배치와 PDF·Word 다운로드 확인

운영 배포는 `dist`만 포함하는 `.deploy/rireki-unified.zip`을 사용합니다. 소스, 비밀 환경변수, Supabase 서버 비밀키는 포함하지 않습니다. Cloudflare 이전 배포로 롤백해도 원본 시안 키가 남아 있어 이전 편집기에서 다시 읽을 수 있습니다.
