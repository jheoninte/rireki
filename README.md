# rireki.

공개 서비스: https://rireki-easy.pages.dev/ · [배포·업데이트 안내](docs/deployment.md)

일본어 우선의 무료 이력서 작성 서비스입니다. 참고 사이트의 사용성을 출발점으로, 아이보리·딥그린과 문서 중심의 독립적인 디자인으로 재구성했습니다. 회원가입 없이 작성부터 다운로드까지 이용할 수 있습니다.

## 실행

```sh
pnpm install
pnpm dev
```

```sh
pnpm build  # 배포용 dist 생성
pnpm test   # 인증 흐름 테스트
```

## 기능

- 일본어 반응형 소개 페이지, 사용 방법, 서식 선택, FAQ
- 4단계 편집기와 실시간 미리보기
- 학력·경력 반복 입력, 증명사진, 예문
- 브라우저 자동 저장, 재방문 복원
- PDF·편집 가능한 Word 다운로드
- 이메일·비밀번호 가입·로그인, Google OAuth, 비밀번호 재설정용 Supabase 연결 코드
- 세션 복원, 로그아웃, 키보드로 조작 가능한 모달
- 추후 다국어 확장을 위한 문구 catalog 분리

## 인증 연결

[인증 설정 안내](docs/auth-setup.md)를 따라 새 Supabase 프로젝트와 Google OAuth를 연결합니다. `.env.example`을 `.env.local`로 복사하고 프로젝트 URL과 공개 키를 설정한 뒤 서버를 다시 시작합니다.

자격 증명이 없는 현재 상태에서는 인증이 활성화되지 않습니다. 로그인 화면에 준비 중 안내를 표시하고 비회원 작성은 정상 제공하며, 가짜 계정 생성이나 가짜 로그인 성공 처리를 하지 않습니다.

## 데이터·문서

이력서는 현재 기기·브라우저에만 저장됩니다. 로그인은 기기 간 동기화나 클라우드 이력서 저장을 제공하지 않습니다. 사진도 브라우저 내부에서 축소·저장됩니다. Google Fonts 사용을 위한 외부 요청은 발생합니다.

PDF는 일본어를 안정적으로 표시하도록 화면을 이미지로 렌더링합니다. 검색 가능한 텍스트 PDF는 아니며, 긴 내용은 여러 페이지로 나뉩니다. Word는 편집 가능한 문서로 생성되어 미리보기와 배치가 다를 수 있습니다. 서식은 자체 디자인이며 공인 JIS 서식이라고 표시하지 않습니다.
