# rireki.

공개 서비스: https://rireki-easy.pages.dev/ · [배포·업데이트 안내](docs/deployment.md)

일본어 우선의 무료 이력서 작성 서비스입니다. 참고 사이트의 사용성을 출발점으로, 시안의 블루·카드형 UI와 문서 중심의 디자인으로 통합했습니다. 회원가입 없이 작성부터 다운로드까지 이용할 수 있습니다.

## 실행

```sh
pnpm install
pnpm dev
```

```sh
pnpm build  # 배포용 dist 생성
pnpm test   # 인증·클라우드·PostgreSQL 권한·결제·크레딧 테스트
```

## 기능

- 일본어 반응형 소개 페이지, 사용 방법, 서식 선택, FAQ
- 시안 디자인을 통합한 카드형 편집기, 섹션 바로가기, 고정 A4 실시간 미리보기
- 학력·경력 반복 입력, 증명사진, 예문
- 계정별 브라우저 자동 저장, 게스트 초안 가져오기, 클라우드 저장·읽기 및 충돌 복구 (서버 설정 후 활성화)
- PDF·편집 가능한 Word 다운로드
- 이메일·비밀번호 가입·로그인, Google OAuth, 비밀번호 재설정용 Supabase 연결 코드
- 세션 복원, 로그아웃, 키보드로 조작 가능한 모달
- 직군별 유료 서식·워터마크, Stripe 단건 결제·서명 검증 웹훅, 서버 크레딧 기반 AI 코칭
- 모바일 입력/미리보기 전환, 직군별 인라인 가이드, 지원 전 체크리스트·채용 탐색
- 기존 `/templates/resume-builder/` 주소를 같은 편집기로 연결, 별도 초안 가져오기·복원
- 추후 다국어 확장을 위한 문구 catalog 분리

## 인증 연결

[인증 설정 안내](docs/auth-setup.md)를 따라 새 Supabase 프로젝트와 Google OAuth를 연결합니다. `.env.example`을 `.env.local`로 복사하고 프로젝트 URL과 공개 키를 설정한 뒤 서버를 다시 시작합니다.

공개 서비스에는 Supabase Auth와 Google 로그인을 연결했습니다. Google 로그인·세션 복원·로그아웃, Resend SMTP를 통한 재설정 메일 전달을 실제로 확인했습니다. 발신 주소는 `no-reply@rireki.jpease.org`입니다. 환경변수 없는 새 체크아웃은 인증 준비 중 안내와 비회원 작성을 제공합니다. 비밀키는 저장소에 포함하지 않습니다.

## 데이터·문서

게스트 이력서는 현재 브라우저에 저장됩니다. 클라우드 기능을 설정한 환경에서는 로그인 후 사용자가 저장·읽기를 선택하면 Supabase에 계정별로 저장하고 이후 변경을 자동 동기화합니다. AI는 동의한 선택 문장과 직군만 OpenAI로 전송합니다. 사진은 브라우저에서 축소합니다. Google Fonts 요청도 발생합니다.

신규 기능은 기본 비활성입니다. [클라우드·결제·AI 설정과 비용 설계](docs/workspace-setup.md)에 마이그레이션, 서버 함수, 소셜 제공자, Stripe 테스트, 예산과 운영 한계를 정리했습니다. 통합 UI는 운영 사이트에 반영했습니다. 클라우드·AI·결제 서버 기능은 별도 설정 전까지 준비 중으로 표시합니다.

PDF는 일본어를 안정적으로 표시하도록 화면을 이미지로 렌더링합니다. 검색 가능한 텍스트 PDF는 아니며, 긴 내용은 여러 페이지로 나뉩니다. Word는 편집 가능한 문서로 생성되어 미리보기와 배치가 다를 수 있습니다. 서식은 자체 디자인이며 공인 JIS 서식이라고 표시하지 않습니다.

- [Supabase·Google 연결](docs/auth-setup.md)
- [다국어 확장](docs/localization.md)
- [최초 참고 사이트 분석](docs/reference-analysis.md)

이전 한국어 프로토타입의 데이터는 삭제하지 않습니다. 일본어 버전의 저장 키는 별도로 관리합니다.

## 통합 서비스

`/`는 소개 페이지이고 `/#builder`는 통합 편집기입니다. 기존 `/templates/resume-builder/`도 `/#builder`로 연결됩니다. 같은 브랜드·로그인·저장 형식·다운로드를 사용합니다. 시안의 이전 브라우저 초안은 원본을 보존하면서 자동/선택 가져오기를 제공합니다. 자세한 내용은 [서비스 통합 안내](docs/service-unification.md)를 참고하세요.

## 콘텐츠·검색 유입 개선 (2026-11-20)

- `/`는 빌드 시 HTML로 생성되는 일본어 랜딩입니다. 편집기 번들 없이 서비스 소개, 자동 저장·무료 출력 안내, 서류별 설명, FAQ와 템플릿 선택 링크가 표시됩니다.
- `/app/`에서 편집기를 실행합니다. `?template=rirekisho`, `work-history`, `developer`, `designer`로 양식을 바로 선택할 수 있습니다. 기존 `/#builder`와 인증 콜백도 연결됩니다.
- 개발자·디자이너는 별도 React 컴포넌트를 사용합니다. 개발자는 기술 스택 사이드바, 디자이너는 포트폴리오 링크를 우선 배치합니다. 기존 PRO 정책을 유지합니다.
- 무료 일본식 履歴書에는 사진, 후리가나, 주소 후리가나, 학력·직력 표, 자격, 지원동기, 본인 희망란이 있습니다. 職務経歴書는 직무요약·상세업무·성과·기술·자기PR 중심입니다. 동일 초안을 전환해 사용합니다.
- 새 필드는 기존 초안에 빈 값으로 추가되며 로컬·클라우드 저장과 PDF·Word 출력에 반영됩니다. Word는 편집 가능한 표/문단으로 생성되므로 PDF와 시각적으로 동일하지는 않습니다.
- 배포 시 기존 마이그레이션에 이어 `supabase/migrations/202611200002_document_templates.sql`을 적용해야 새 두 양식의 클라우드 저장을 허용합니다.
- 빌드는 반드시 `pnpm build`를 사용합니다. `vite build`만 직접 실행하면 정적 랜딩과 `/app/` 엔트리가 생성되지 않습니다. `pnpm preview`로 최종 결과를 확인할 수 있습니다.
